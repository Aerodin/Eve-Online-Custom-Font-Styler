EVE Custom Font Styler

Type names for ships, containers and anything else you can name in EVE, one per line, then copy styled versions built only from characters EVE Online's font can display.

Styled names
Underlined characters aren't in EVE's font and will show as boxes in game.
Names marked in red are over the limit, so EVE's rename box will cut them off. Shorten them or pick a style that adds fewer characters.

Every style

Your first name in each style. Select one to switch the converter to it.

Letter map

Pick which lookalike each letter uses in this style. Greyed letters have no true match, so they fall back to a plain character. Your choices are saved in this browser.

Character library

Every character in EVE's font list. Click one to add it to the compose bar at the bottom of the screen, then copy the result.

Made by Aerodin.

The character library is built from the full EVE Online font list compiled by u/Agitated-Device9837, shared across two Reddit posts many years ago. Thanks for putting it together.

Always test a name in the rename box before committing, since EVE's name filter may reject characters the font can display.

Styled names still have to follow the EVE Online Naming Policy, which covers ship names and every other player-nameable item. GMs judge what a name says, not how it's spelled, so lookalike characters don't make an offensive name acceptable.
