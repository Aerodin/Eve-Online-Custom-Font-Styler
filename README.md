# EVE Custom Font Styler

Style names for ships, containers and other items in EVE Online using only
characters the game's font can display. Type a name, pick a style, and copy
the result straight into EVE's rename box.

**Use it here:** [https://aerodin.github.io/eve-custom-font-styler/](https://aerodin.github.io/Eve-Online-Custom-Font-Styler/)

## Features

- **14 styles:** Small caps, Curvy, Obscure, Cryptic, Faux Cyrillic, Greek,
  Accented, Upside down, Bubble, Bracketed, Strikethrough, Underline,
  Slashed and Plain
- **Every style preview:** see your name in all styles at once and copy any of them
- **Letter map:** choose which lookalike character each letter uses
- **Roman numerals:** numbers written as digits or words become Roman numerals
  (7 or seven becomes VII)
- **Bracket options:** 15 bracket types, wrapping each letter, each word or
  the whole name, with adjustable bracket padding
- **Padding:** space out characters from 0 to 5 spaces in any style
- **Name limit:** counts characters and flags names over EVE's 20-character
  ship name limit (adjustable for other items)
- **Character library:** browse every character in EVE's font, with notices
  for right-to-left characters and attaching marks
- **Compose bar:** click characters to build a custom name by hand
- **Sample names:** generate fresh industrial sci-fi names to try out styles

Settings are saved in your browser, and nothing is sent anywhere.

## Tips

- Always test a name in EVE's rename box before committing to it.
- Styles built from attaching marks (Cryptic, Strikethrough, Underline and
  Slashed) add characters quickly, so they suit shorter names.
- Right-to-left characters such as Arabic can appear reordered next to
  other text. A single one at the start or end of a name is the most predictable.

## Naming policy

Styled names must still follow the
[EVE Online Naming Policy](https://support.eveonline.com/hc/en-us/articles/8563435867804-EVE-Online-Naming-Policy),
which covers ship names and every other player-nameable item. Lookalike
characters don't make an offensive name acceptable.
